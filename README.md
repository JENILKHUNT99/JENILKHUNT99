## 🏆 Featured Projects

### [CryptoCurrency ETL Pipeline](https://github.com/JENILKHUNT99/Crypto_ETL) 
A production-grade, containerized batch ETL pipeline with industry-standard tools.

**Tech Stack:** Python, Apache Airflow, dbt, PostgreSQL, Docker, AWS S3

**Key Features:**
- 🔄 **Orchestrated ETL** with Apache Airflow (hourly scheduling, retry logic, alerts)
- 📊 **Data Warehouse** with star schema (dimensions, facts, audit tables)
- 🧪 **dbt Transformations** with data quality tests and documentation
- 🔒 **Security-first** design (input validation, SQL injection prevention)
- 📁 **Partitioned Storage** by date/hour for efficient querying
- 🐳 **Docker Compose** for one-command deployment
